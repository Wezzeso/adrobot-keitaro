# Adrobot

Небольшая обёртка над Keitaro для создания кампаний и редактирования офферов. FastAPI обслуживает интерфейс и API. SQLAlchemy и Alembic отвечают за локальную базу, где сохраняются архив офферов и закреплённые доли.

## Быстрый старт

Понадобится Python 3.11 или новее. Выполните команды из корня репозитория.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[test]'
alembic upgrade head
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). По умолчанию запускается деморежим с SQLite, тестовыми справочниками и одной кампанией. Для новой кампании укажите название, код страны, оффер, домен, группу и источник.

## Как проверить редактор

1. Откройте поток офферов демонстрационной кампании. Найдите оффер по названию или ID и добавьте его. Доли перераспределятся, а поток перейдёт в черновик.
2. Нажмите «Отменить», чтобы вернуться к опубликованной версии. Снова добавьте оффер и нажмите «Опубликовать».
3. Снимите оффер и опубликуйте изменения. Оффер останется в архиве с долей 0%. Кнопка «Вернуть» добавляет его обратно в черновик.
4. Закрепите долю активного оффера. При добавлении или удалении другого оффера распределится оставшаяся доля. Сумма активных долей всегда должна составлять 100%.

«Обновить потоки» загружает их текущий состав из Keitaro. Если ранее показанный оффер удалили в трекере, он появится в архиве. Если состав или доля в трекере изменились после загрузки, редактор попросит обновить поток перед публикацией. При выборе потока редиректа редактор покажет, что в нём нет офферов.

## Подключение Keitaro

Скопируйте `.env.example` в `.env`. Укажите корневой HTTPS-адрес тестового трекера в `KEITARO_BASE_URL` и ключ Admin API в `KEITARO_API_KEY`. Загрузите переменные перед запуском.

```bash
set -a
source ./.env
set +a
alembic upgrade head
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Название получает префикс `test_ryabov_`. Первый поток направляет выбранную страну на Google, второй направляет остальные переходы на выбранный оффер с долей 100%. Кампания создаётся выключенной для проверки. В редакторе доступны кампании с этим тестовым префиксом. Изменения публикуются только в выбранный поток офферов. Ключ хранится на сервере.

## Проверки

```bash
python -m pytest -q
alembic check
```

Тесты покрывают создание обоих потоков через Admin API, чтение после публикации, сохранение архива и закреплений после перезапуска и конфликт при внешнем изменении офферов.

На учебном стенде проверена кампания `test_ryabov_Routing QA`. В первом потоке сохранён фильтр по стране `GM` и адрес Google, во втором опубликованы офферы с суммой долей 100%. Там же проверены отмена черновика, закрепление доли, восстановление оффера и появление в архиве после удаления через API и обновления редактора.

Если трекер отклонит создание потока, приложение покажет ID уже созданной выключенной кампании. По этому ID можно проверить её состояние перед повторной попыткой.
